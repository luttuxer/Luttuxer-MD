🤖 Luttuxer MD

A personal WhatsApp bot built with Baileys and running on Termux.

✨ Features

- 🏓 Ping & latency
- ❤️ Alive message
- 👑 Owner command
- 📜 Command menu
- 🖼️ Sticker creation
- 🔄 Sticker to image
- 👁️ View-once media
- 🎙️ Mention voice reply
- ⚡ Fast WhatsApp automation

📋 Commands

.ping
.alive
.owner
.menu
.sticker
.s
.photo
.toimg
.vv

🛠️ Setup

git clone https://github.com/luttuxer/Luttuxer-MD.git
cd Luttuxer-MD
npm install
node index.js

⚠️ Important

Never upload WhatsApp authentication files, passwords, API keys, or other private credentials to GitHub.
